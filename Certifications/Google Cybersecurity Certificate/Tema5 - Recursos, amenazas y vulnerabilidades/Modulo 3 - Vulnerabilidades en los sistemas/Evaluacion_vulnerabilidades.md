# Evaluación de vulnerabilidades

Una evaluación de vulnerabilidades es ​el proceso de revisión interna de los sistemas de seguridad de una organización. ​Estas evaluaciones funcionan de forma similar al proceso de identificación y categorización de ​vulnerabilidades ​en la lista de CVE. 

En general, el objetivo de una evaluación de vulnerabilidades es identificar puntos débiles y prevenir ​ataques. ​También son el modo en que los equipos de seguridad determinan si sus controles de seguridad cumplen los ​Estándares normativos. ​Las organizaciones realizan evaluaciones de vulnerabilidades con mucha frecuencia.

Estas evaluaciones siguen 4 pasos:

- **1r paso: Identificación:** Se utilizan herramientas de exploración y pruebas manuales para encontrar vulnerabilidades. El objetivo es comprender el estadoa ctual del sistema de seguridad.

- **2do paso: Análisis de vulnerabilidades:** Se comprueba cada una de las vulnerabilidades que se encontraron. El objetivo es encontrar el origen del problema.

- **3r paso: Evaluación de riesgos:** Se asigna una puntuación a cada vulnerabilidad. Esta puntuación se asigna en función de dos factores, que son: la gravedad del impacto si se explota esa vulnerabilidad y la probabilidad de que esto pueda ocurrir. 

- **4to paso: Reparación:** Se abordan las vulnerabilidades que puedan afectar a la organización. Se produce en función de la puntuación de gravedad asignada durante el proceso de evaluación de riesgos. Esta parte se suele hacer en conjunto entre el personal de seguridad y los equipos de informática para idear el mejor enfoque para corregir las vulnerabilidades descubiertas.
