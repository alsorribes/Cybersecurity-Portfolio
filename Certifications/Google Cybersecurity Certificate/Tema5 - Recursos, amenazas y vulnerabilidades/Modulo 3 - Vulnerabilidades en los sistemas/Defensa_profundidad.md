# Estrategia de defensa en profundidad

Una defensa de capas es dificil de penetrar. Cuando una barrera falla, otra ocupa su lugar para frenar el ataque. La defensa en profundidad es un modelo de seguridad que hace uso de este concepto para reducir el riesgo de las vulnerabilidades. 

Este modelo consta de 5 capas en su diseño dónde cada capa incluye una seria de controles de seguridad que protegen la información a medida que entra y sale del modelo.

- **1ra capa --> Capa perimetral:** Incluye tecnologias como nombres de usuario y contraseñas. Suele ser una capa de autenitcación de usuarios.
- **2da capa --> Capa de red:** Esta formada por firewalls principalmente.
- **3ra capa --> Capa de punto final:** Hace referéncia a los dispositivos que tienen acceso a la red como un ordenador. Tecnologias que protegen a estos dispositivos son los software antivirus.
- **4ta capa --> Capa de aplicación:** Incluye todas las interfaces que se usan para interactuar con la tecnología. En esta capa, las medidas de seguridad se programan como parte de una aplicación. Un ejemplo seria la autenticación de múltiples factores.
- **5ta capa --> Capa de datos:** Se encuentran los datos críticos que tenemos que proteger como la información de identificación personal.
